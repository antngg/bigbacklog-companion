Папки с играми

Для игр не из магазинов, например копий с GOG без Galaxy или старых игр. Приложение замечает, когда запущена игра из этих папок, и считает время. Каждая подпапка становится отдельной игрой и появляется на сайте на полке GOG после первого запуска. Список папок остается на компьютере, на сайт уходит только название игры.
